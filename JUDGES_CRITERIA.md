## Track-Specific Review Focus

### RWA Applications Track (Highest Priority)
- **Authenticity of assets** (real value, real-world backing)
- **Business loop completeness** (full operation cycle)
- **Compliance feasibility** (regulatory considerations)

### AI Native Applications Track
- AI must serve as **core capability or on-chain decision-making entity**
- Participation in:
  - On-chain asset issuance
  - Trading
  - Automated execution
  - Business processes
- NOT merely: auxiliary copywriting, simple chat, or third-party AI API calls only

## What Each Dimension Actually Means

### Product Completion (30%)
- Does it have a full loop? Can anyone use it end-to-end?
- Is it polished and production-ready, or is it half-built?
- Does it feel like a finished product or a prototype?
- **Key:** Incomplete products score 0, regardless of innovation

### BOT Chain Mainnet Integration (25%)
- Is it actually on BOT mainnet (not testnet)?
- Does it use BOT-native features (bridge, DEX, staking)?
- Or is it a generic EVM app that could deploy anywhere?
- Contracts must be verified on scan.botchain.ai
- Wallet connection must enforce Chain ID 677

### Innovation (20%)
- Is this something new? Or a copy of existing tooling?
- Does it introduce a novel mechanism or approach?
- Can other builders learn from it?
- **Key:** Innovation only matters if product is complete

### User Experience (15%)
- Can a judge complete the core flow in 90 seconds without explanation?
- Does it feel intentional and designed?
- Error states handled? Loading states clear?
- Mobile-friendly?

### Technical Quality (10%)
- Clean code structure?
- Verified smart contracts?
- Proper error handling?
- Gas-efficient transactions?
- Events emitted for all critical actions?

## Judge Psychology (Inferred from Past Winners)

| Pattern | Evidence |
|---------|----------|
| Completeness > Novelty | DevStation (IDE) won over more innovative projects |
| Focused primitives > Broad protocols | BOTSpend (one feature) beat broader projects |
| Live demo > Architecture | Rheon won with streaming demo, not just specs |
| Public frontend + working contracts | CipherBallot (gold) had both |
| Tooling > Applications | DevStation helped all builders, not just one use case |
